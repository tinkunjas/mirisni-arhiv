# Kopiranje ponude za WhatsApp i Facebook

Na stranici **Moji parfemi** klikni **Kopiraj popis za WhatsApp**. Popis automatski uključuje samo aktivne bočice označene `Za zamjenu` ili `Za prodaju`, zajedno u jednoj abecedno sortiranoj listi s naslovom **PARFEMI ZA PRODAJU/ZAMJENU**. Prikazuje preostale mililitre, a ne privatne ocjene.

Na kraju stoji **Cijene i detalji na upit.** Popis ne dijeli ponudu u dvije odvojene kategorije.

Zatim otvori WhatsApp ili Facebook poruku i zalijepi pomoću `Ctrl + V`. Kopirani sadržaj odražava trenutačno učitane podatke sa Supabasea.

Za objavu zamijeni datoteke u lokalnom GitHub repozitoriju i izvrši `git add .`, `git commit -m "Finalni popis za prodaju i zamjenu"`, `git push origin main`. Nije potreban novi SQL za ovu promjenu.
